# Verification

Verification is evidence against the original objective.

Order of preference:
1. existing deterministic tests/checks
2. targeted deterministic checks
3. runtime/integration observation
4. independent verifier when it adds meaningful confidence

A verifier receives the objective, acceptance criteria and integrated implementation. Do not prime it with another agent's conclusion.

A PASS requires evidence for applicable acceptance criteria. Unknowns must remain explicit rather than being converted into confidence statements.
