# Context Economy

Treat the Curator context as scarce.

- L0: Curator active context — objective, decisions, integration state.
- L1: agent private context — disposable exploration/execution context.
- L2: durable project artifacts — contracts, decisions, evidence worth preserving.

Agents should receive only what they need and return compressed evidence rather than full investigation history.

Prefer file/symbol references and concise conclusions over copied source code.

Do not use an agent when the coordination and result tokens are likely to exceed the context it saves.
